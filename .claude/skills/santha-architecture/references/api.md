# REST surface (/v1) — representative
Auth: POST /auth/otp/request · POST /auth/otp/verify · POST /auth/refresh · POST /auth/logout · POST /auth/ops/login (email+password → OTP) · POST /auth/ops/verify
Config: GET /serviceability?lat&lng (public) · GET /config/flags?microMarketId
Consumer: GET /serviceability?lat&lng · GET /feed?lat&lng&tab&openNow&selfDelivered&maxEta (public) · GET /search?lat&lng&q&veg&openNow (public, grouped by store) · GET /catalogue/categories?type (public) · GET /stores/{id} · GET|PUT|DELETE /cart · POST /cart/price (address + asap|slot + promoCode → quote) · POST /orders (Idempotency-Key) · GET /orders · GET /orders/{id} · POST /orders/{id}/abandon-payment · POST /orders/{id}/cancel · POST /orders/{id}/issues · POST /orders/{id}/rating · GET /wallet · GET /me · PUT /me/addresses
Merchant: POST /merchants · GET /merchants/me · PATCH /merchants/me · PUT /merchants/me/kyc/{pan|gstin|gst-exemption|fssai|bank|drug-licence} · POST /merchants/me/kyc/aadhaar/{start|verify} · DELETE /merchants/me/staff/{id} · POST /merchants/me/submit · PUT /merchants/me/availability · POST /merchants/me/staff · PUT /merchants/me/photos · GET /merchants/me/categories · GET|POST /merchants/me/items · GET|PATCH|DELETE /merchants/me/items/{id} · PUT /merchants/me/items/{id}/stock · POST /merchants/me/items/confirm · POST /merchants/me/items/import (dryRun) · POST /merchants/me/items/approve · GET|PUT /merchants/me/slots · POST /merchants/me/media → PUT presigned URL → POST /merchants/me/media/{id}/complete · GET /catalogue/barcodes/{code} (404 BARCODE_UNKNOWN) · GET /catalogue/master?q · GET /merchants/me/orders · POST /orders/{id}/accept (body: fulfilment_mode, staff_id?) · POST /orders/{id}/reject · POST /orders/{id}/items/{iid}/unavailable · POST /orders/{id}/ready · GET /merchants/me/statements
Rider: PUT /riders/me/status · GET /offers · POST /offers/{id}/accept · POST /offers/{id}/decline · POST /jobs/{id}/picked-up · POST /jobs/{id}/delivered · POST /riders/me/location · GET /riders/me/earnings
Staff link (self-delivery): GET /staff-jobs/{token} · POST /staff-jobs/{token}/picked-up · POST /staff-jobs/{token}/delivered
Payments: POST /payments/{intentId}/confirm (Idempotency-Key; intent created by POST /orders) · POST /webhooks/razorpay · POST /webhooks/kyc · POST /webhooks/whatsapp
Ops (/ops, RBAC: admin, ops, finance, support): merchants?status · merchants/{id} · merchants/{id}/approve|reject|go-live|pause|offboard · promos (GET, POST, PATCH /{id}) · micro-markets (GET, POST) · micro-markets/{id} · micro-markets/{id}/versions (POST) · catalogue/summary · catalogue/items?status|merchantId · catalogue/items/{id}/review · catalogue/media · catalogue/media/{id}/review · catalogue/barcode-requests · catalogue/master (POST, enrichment) · catalogue/merchants/{id}/items (POST, PATCH /{itemId}, POST /import — assisted entry) · catalogue/staleness-sweep · micro-markets · orders/live · orders/{id}/reassign · refunds · disputes · settlements/run · reconciliation · moderation · audit
WebSocket rooms: order:{id} · merchant:{id} · rider:{id}; events mirror domain events relevant to the room.
Dev (fake mode only, 404 otherwise): PUT /dev/uploads (in-memory presigned target) · GET /dev/media/* · GET|POST /dev/clock (move the clock forward, e.g. 73 h to see staleness) · POST /dev/payments/{intentId}/{succeed|fail} (mock payment sheet) · POST /dev/jobs/payment-expiry.
